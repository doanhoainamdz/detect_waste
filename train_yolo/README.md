# Trọng số và nhật ký YOLO

- `best6.pt`: checkpoint YOLO26s với 7 lớp, quản lý bằng Git LFS.
- `results.csv`: nhật ký huấn luyện 83 epoch, được giữ nguyên từ dự án gốc.

Chạy `git lfs pull` nếu checkpoint chưa có hoặc chỉ là file văn bản vài dòng. Checksum nằm trong `../models_manifest.json`. Chưa xác minh CSV là nhật ký của chính checkpoint này; xem `../docs/MODEL_CARD.md` trước khi trích dẫn kết quả.
